# Sticky Rice FC Documentation

This folder contains user guides and documentation for the Sticky Rice FC web app.

## Admin Guides

- **QR-CODE-UPLOAD-GUIDE.md** - How to upload and manage payment QR codes from the admin panel
- **WAITLIST-AUTO-PROMOTION.md** - How the automatic waitlist promotion system works
- **PROFESSIONAL-UI-UPDATES.md** - Overview of all professional UI improvements

## For Admins

Start with the QR-CODE-UPLOAD-GUIDE.md to learn how to:
- Upload payment QR codes without accessing Supabase
- Set payment amounts for each game
- Manage announcements and game settings

## For Developers

The PROFESSIONAL-UI-UPDATES.md file documents all the UI/UX improvements including:
- Toast notification system
- Professional modal dialogs
- SVG icon replacements
- Mobile-responsive design patterns
